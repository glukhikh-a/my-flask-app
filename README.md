# my-flask-app
# Лабораторная работа 2 — уязвимости веб-приложения

> **Учебный проект.** Выполнено в рамках лабораторной работы по дисциплине,
> связанной с информационной безопасностью. Цель — на простом примере
> показать, как работают две уязвимости из классификации
> [OWASP Top 10](https://owasp.org/Top10/), как их можно эксплуатировать и
> как исправлять. Приложение запускается только локально
> (`127.0.0.1`), не предназначено для продакшена и не публиковалось
> в открытом доступе в рабочем виде.

Flask-приложение: регистрация, логин, комментарии в профиле.
Две уязвимости (OWASP Top 10, A03:2021 — Injection):

1. SQL-инъекция в форме логина (обход аутентификации)
2. Хранимая XSS в комментариях профиля

## Файлы

- `app.py` — уязвимое приложение
- `exploit.py` — эксплуатация обеих уязвимостей
- `patch.diff` — исправление

## Запуск приложения

```bash
pip install flask
python3 app.py
```

http://127.0.0.1:5000, тестовый пользователь `admin / Sup3rSecretAdminPass!`

## Запуск эксплойтов

Сервер должен быть запущен в соседнем терминале.

```bash
pip install requests
python3 exploit.py          # обе атаки
python3 exploit.py sqli     # только SQL-инъекция
python3 exploit.py xss      # только XSS
```

## Применение патча

```bash
patch -p1 < patch.diff
pip install werkzeug        # для check_password_hash / generate_password_hash
python3 app.py
python3 exploit.py          # теперь обе атаки должны проваливаться
```

## Дисклеймер

Код `app.py` намеренно уязвим и создан исключительно для учебной
демонстрации конкретных пунктов OWASP Top 10 в рамках лабораторной
работы. Он не содержит функций атаки на сторонние системы — `exploit.py`
обращается только к `127.0.0.1` (локально запущенному собственному
экземпляру приложения) и не предназначен для использования против
чужих сайтов или сервисов. Не используйте показанные здесь паттерны
(сборка SQL-запроса через f-строку, `|safe` для пользовательского ввода)
в реальных проектах — корректный вариант показан в `patch.diff`.
